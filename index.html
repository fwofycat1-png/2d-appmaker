Quick start

Get started in 3 steps

01 · Download

Download and extract the source ZIP above. Make sure Python 3.10+ is installed.

02 · Install dependency

Open a terminal in the extracted folder and run:

python -m pip install pygame-ce
03 · Launch the editor

Run the Python application:

python 2d_appmaker_v65.py

On some Macs, replace python with python3. For command reference, see the coding manual.
